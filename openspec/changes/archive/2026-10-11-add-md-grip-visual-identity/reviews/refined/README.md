## 渲染与观察证据（阶段一）

- 工具：`rsvg-convert 2.62.2`、`ImageMagick 7.1.2-29`，macOS arm64。
- 方法：18 px / 16 px 按 1× 设备像素真实渲染后 `-scale 1600%` 放大观察；像素抽样核验：
  - 18 px：缝隙列 (6‑7, 9) 全透明、窗列 (15, 9) 实心、右侧 (16‑17, 9) 透明留白 2 px。
  - 16 px：窗前缝 (5, 9) 透明 + 描边羽化约 0.5、窗内 (7, 9) 实、右缘 (15‑16, 9) 透明。
- 迭代记录：初版镂空环在窗圆角处缝隙收窄；随后像素抽样发现 evenodd 镂空环子路径在不与页体重叠处自填充（"垫板"），致 18/16 px 右缘零留白；统一改为单轮廓构造恢复呼吸空间，favicon 窗块改回横版（7×6.5）。
